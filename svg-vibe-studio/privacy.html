Privacy

SVG Vibe Studio is designed as a browser-based editor. Project text, settings and session presets are handled locally by the browser unless a user explicitly chooses an external service or browser feature.

Local data

Session presets and editor state may be stored in browser storage. Exported files are created in the browser.

External resources

The application may load browser resources such as fonts where configured. Review your deployment's network policy if you require a fully self-contained environment.

Your deployment

If you publish this project yourself, update this page to reflect any analytics, third-party services, hosting logs, or other processing that you add.
