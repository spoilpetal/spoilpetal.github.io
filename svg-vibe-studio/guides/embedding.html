Using the generated SVG

The portable output is the SVG file itself. You can keep it in a repository, serve it from a website, or package it as an application asset.

PlatformWhere to put itHow to use it
GitHub READMECommit vibe.svg to the repository.
![SVG Vibe](./vibe.svg)
GitHub renders the committed SVG as an image.
GitHub PagesPut vibe.svg anywhere under the published Pages directory.
<img src="./vibe.svg" alt="SVG Vibe">
Normal websitePut it in your public/static/assets directory.Reference it with an <img>, CSS background, or inline SVG.
Web appUse your app's public/static asset folder.Reference the file from the framework's normal static-asset path.
Desktop/mobile appBundle it as an application resource.Load the bundled SVG using the platform's asset/resource mechanism.
