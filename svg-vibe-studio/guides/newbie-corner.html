Newbie Corner

1. Make your animation

Configure text, animation mode, cursor, effects, frame, size and FPS in the Studio.

2. Export SVG

Use Download SVG or Copy SVG code. The result is a normal SVG document and does not need SVG Vibe Studio to run.

3. Put it in your project

For the simplest workflow, save it as vibe.svg and place it beside the page that will use it.

my-project/
├── index.html
└── vibe.svg

4. Display it

<img src="./vibe.svg" alt="Animated SVG">

For inline SVG, open the file, copy its <svg>...</svg> contents and place them in an HTML document.
