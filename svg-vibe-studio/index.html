04 · Animation

Brute-force mode works per character: each letter cycles through candidate glyphs until that character locks, then the next character starts. It does not try to guess the whole word as one block.

Plain Print Lab — clean typing + cursor

Clean Typing reveals the text normally and keeps the cursor. Optional motion can be applied to each character or to the whole canvas after the typing settles.

09 · Motion lab — keyframes & layers

Keyframes are small timed instructions layered on top of the typing engine. They are deliberately simple: pick a time, choose a motion, and set its amount.

Live keyframe status

Effect layer stack

How to use the uploaded SVG

Overlay/background/frame: the SVG is placed as a reusable visual layer. Letter: put :svg: in your text and the studio replaces that token with the uploaded artwork. This is useful for logos, custom letters, icons and badges.

11 · SVG export

The generated SVG is the portable output. Copy it into another project or download it as .svg. No renderer URL or separate service is required.

Generated SVG
Resource note: lower FPS, smaller canvas dimensions, shorter animation duration and fewer visual effects generally mean less browser RAM use and smaller raster/GIF exports. SVG size is affected mainly by scene complexity, paths, filters and embedded assets—not FPS alone.
How to use the SVG

Save the generated code as vibe.svg, or use the downloaded file. The Guides section explains how to place it in GitHub Pages, a web page, or an application.
