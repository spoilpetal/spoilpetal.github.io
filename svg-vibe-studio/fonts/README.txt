Vibe Mono Study — install-safe bundled font

The bundled TTF/WOFF/WOFF2 are a renamed, install-safe monospaced font distribution used so desktop font installers have a conventional, complete font with broad Unicode coverage. The editable .vfont.json remains the SVG Vibe Studio source format and can be edited/re-exported from Font Maker.

Install the TTF itself on Windows/macOS/Linux. Extract ZIP archives first.
